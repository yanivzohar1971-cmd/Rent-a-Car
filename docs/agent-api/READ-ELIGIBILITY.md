| `terms.load.effective` | terms | Same blocker as `reservation.terms.effective`: repository uses global current-user state. Needs uid-parameterized port + params `supplierId`, `language`. |

| `priceList.details.view` | price_lists | Local Room reads (price list groups/models). Needs a dedicated read port and DTOs; large payloads need pagination. |
| `yard.smartPublish.load` | yard | Candidates derive from fleet/yard data (partly cloud). Needs a fleet-scoped port; defer until yard cloud semantics are defined. |
| `settings.sync.check` | settings | `DataSyncCheckRepository` compares local vs cloud counts and calls the cloud. A safe version would be a local-counts-only port reporting `syncStatus=UNKNOWN`; not implemented to avoid implying sync verification or triggering network I/O. |
